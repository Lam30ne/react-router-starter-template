# Regulate — Trademark Status

## Current Status

The name "Regulate" has **not** been legally cleared for commercial use.

## Actions Required

1. **Professional trademark search** — Engage a trademark attorney to conduct a comprehensive search across relevant classes (Class 9: software, Class 42: SaaS, Class 44: health/wellness apps)
2. **Common law search** — Check for unregistered uses in the wellness, meditation, and ambient sound app space
3. **Domain availability** — Check availability of regulate.app, getregulate.com, and similar domains
4. **App store conflicts** — Search iOS App Store and Google Play for existing apps named "Regulate"

## Risk Assessment

"Regulate" is a common English word, which presents both advantages (less likely to be exclusively owned) and challenges (harder to protect, more likely to conflict with other uses).

## Interim Measures

- Brand name is centralized in `app/lib/constants.ts` via the `BRAND` object
- Changing the name requires updating only the `BRAND` constant
- No brand assets (logos, wordmarks) have been created yet

## Timeline

This should be resolved before any public launch or marketing activity.
